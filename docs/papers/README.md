## Full texts kept in this folder

Four papers are kept here as Markdown copies of their web (HTML) versions, saved in 2025–2026 for a non-commercial university course project so that the design notes can quote them. Copyright stays with the authors and publishers. Each paper was published under the Creative Commons Attribution 4.0 licence ([CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)), which allows redistribution with attribution. The only change made here is the conversion to Markdown, which left some page artefacts in the text (for example arXiv's "Report issue for preceding element" lines). If you hold the rights to one of these texts and want it removed, please open an issue on this repository and it will be taken down.
