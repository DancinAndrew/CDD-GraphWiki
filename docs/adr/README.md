# Architecture Decision Records

This directory records architecture decisions for CDD-GraphWiki.

Use ADRs for decisions that affect system structure, data modeling, dependencies, source boundaries, governance, or evaluation. Use OpenSpec for requirements, scenarios, acceptance criteria, and implementation tasks.

## ADR Template

```markdown
# ADR N: Title

Status: Proposed | Accepted | Superseded
Date: YYYY-MM-DD

## Context

## Decision

## Alternatives Considered

## Consequences
```
