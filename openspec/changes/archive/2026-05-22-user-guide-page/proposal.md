# 系統使用教學手冊頁面新增提案 (User Guide Page Addition Proposal)

## 1. 動機 (Why)
為了讓合規官與系統使用者能更直觀、深入地理解並流暢操作此合規系統，我們需要在系統左側導航欄的「法規自主導入」分頁下方，新增一個「系統使用手冊 (User Guide)」的全新互動式頁面。
本系統融合了多項尖端技術（例如：NVIDIA NIM 平台大語言模型、Neo4j 圖資料庫、SHA-256 防篡改稽核日誌鏈、樹狀切片與雙層抽取防護等），合規官在使用時，需要一個高度可視化、精美且清晰的指引，來理解每個頁面的具體功能、如何使用以及背後採用的核心技術。這有助於降低系統導入的學習曲線，並體現本系統的尖端技術實力。

## 2. 變更範圍 (What Changes)
- **新增系統手冊頁面組件 (`UserGuide.tsx`)**：
  - 採用極致奢華的暗色霓虹美學與毛玻璃玻璃擬態（Glassmorphism）卡片設計。
  - 使用互動式的摺疊面板（Accordion）或分頁（Tabs），詳細說明系統五大核心模組（工作台總覽、案件審查隊列、防篡改稽核、法規可視化圖譜、法規自主導入）的「功能簡介」、「使用指引」與「底層技術架構（包含條款級溯源與防範通用 RAG 理念）」。
  - 內嵌精美的 Markdown 格式與圖形化系統數據流 Mermaid 架構圖。
- **左側導航欄變更 (`Sidebar.tsx`)**：
  - 在「法規自主導入」分頁正下方，追加「系統使用手冊」分頁。
  - 引入並使用 `lucide-react` 的 `BookOpen` 圖標。
  - 無縫對齊現有的選中樣式、霓虹懸停效果與防篡改狀態顯示。
- **主路由分發變更 (`App.tsx`)**：
  - 新增 `guide` 狀態路由分支，在點擊「系統使用手冊」時，流暢加載並渲染該手冊組件。

## 3. 系統能力 (Capabilities)
- **系統導航能力**：使用者能隨時透過側邊欄一鍵切換至「系統使用手冊」分頁，且該分頁具有與其他分頁一致的精美玻璃磨砂外觀與動畫。
- **互動式教學能力**：以高質感的 UI 架構提供合規官生動的技術與業務引導，支援對五大頁面做深度展開，內含詳盡的技術對照，並有結構化的流程圖與步驟指引。

## 4. 影響範圍 (Impact)
- **前端展示層**：新增一個頁面與側邊欄按鈕。由於本系統使用基於 HSL 變數的 vanilla CSS，不依賴 Tailwind，因此不會影響現有樣式，且具有極高的樣式一致性。
- **後端與數據層**：此功能為純前端之教學指引，不對後端 API、Neo4j 資料庫或防篡改自檢邏輯造成任何破壞性變更，對現有業務運作完全無害，是安全且極具價值的增量變更。
